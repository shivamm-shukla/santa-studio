# Code of Conduct

## The short version

Be decent to people. Assume they meant well. Remember that somebody asking an
obvious question is somebody who decided this project was worth their time.

## What is expected

- Talk about the work, not the person. "This function does not handle an empty
  list" is a review. "You clearly did not think about this" is not.
- Assume the other person is reasonable and has context you do not.
- Say when you are wrong. It costs nothing and it makes everybody else safer to
  be wrong in front of.
- Be patient with beginners. This project explicitly invites people who have
  never contributed to anything before, and that invitation is worth nothing if
  the first question they ask gets a curt answer.

## What is not acceptable

- Harassment, insults, or personal attacks of any kind.
- Comments about somebody's identity — nationality, religion, gender, sexuality,
  disability, age, appearance, or the language they speak or write in.
- Unwelcome attention of a sexual nature.
- Publishing somebody's private information.
- Sustained disruption: derailing threads, reopening settled decisions to make a
  point, or arguing in bad faith.

English is a second language for many people here, including in this project's
own documentation. Nobody is to be corrected on their English unless they asked.

## Scope

This applies in issues, pull requests, commit messages, code comments, and
anywhere else somebody is representing the project.

## If something goes wrong

Report it to the maintainer, privately, through a GitHub direct message or by
email if you have it. Reports are read, taken seriously, and not shared beyond
what handling them requires.

The maintainer may edit or remove comments, close threads, or block accounts,
and will say why when doing so unless saying why would make things worse for the
person who reported it.

There is no committee here — this is a project maintained by one person, and
that is worth being honest about rather than describing a process that does not
exist.
